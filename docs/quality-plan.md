# 第一阶段代码质量整理

目标是让开场和月亮首屏的维护入口可读、失败可以诊断、复用有明确边界，保持已验证的画面和帧时间。

1. 先用行为测试锁定播放器几何精度、视口裁切、时钟和时间轴缓存，再整理播放器构造器及语义命名。保留浮点运算顺序、场景 ID 和素材内容。
2. 为存储拒绝访问、图片解码失败和重试建立失败测试，再修复启动路径。
3. 用 Babel 的作用域绑定分析修复提取器，执行真实 ESM 的遮蔽变量、循环依赖与 live export 测试；原始恢复结果输出到独立对照目录，禁止覆盖维护源码。
4. 整理时间轴基类和工厂入口，保留旧派生构造器需要的 `.call()` 协议。
5. README 链接模块职责、依赖、复用示例、数学不变量和验证范围，标注尚未语义整理的恢复模块。
6. 独立审查改动，运行单元测试、真实浏览器交互、双 DPR 逐帧截图对比；记录任何非零差异，然后提交、推送和部署。

验收按具体行为和对照结果判断，不用测试数量或格式化程度代替质量证明。
